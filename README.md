# MiniLLM

MiniLLM is a small GPT-style decoder-only Transformer language model built from scratch in PyTorch.

The first version trains a character-level language model on Tiny Shakespeare and generates text one character at a time.

## Current milestone

- Character-level tokenizer
- Decoder-only Transformer
- Causal self-attention
- Training loop
- Validation loss
- Text generation

## Goal

This project is for learning the internal mechanics of Transformer language models, not for building a production-scale chatbot.
